# Equinox Assessment - Admin Dashboard
An admin dashboard built with **NextJs**, **TypeScript**, **Tailwind CSS**, and **Redux Toolkit**

## Features
- NextJs App Router
- Admin layout (Sidebar, Navbar, Footer)
- List page with:
  - Table view via https://pokeapi.co/api/v2/berry/
  - Search, sort, pagination
  - Detail & edit actions
- Form page:
  - Add & Edit modes
  - Save via [FakeStoreAPI](https://fakestoreapi.com/products) (POST / PUT)
  - Success alert modal
- Multiple language support (EN / ID)
- Redux Toolkit + redux-persist (state survives refresh)

## Tech Stack
- NextJs
- React + TypeScript
- Tailwind CSS
- Redux Toolkit and Redux persist
- next-intl
- FakeStoreAPI and pokeapi

## Getting Started
### Install dependencies
```bash
npm install
```
### Run locally
```bash
npm run dev
```
Open: http://localhost:3000
